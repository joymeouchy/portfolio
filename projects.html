transcendence: PONG_XP

PONG_XP is a full-stack web app built around a real-time, online multiplayer version of Pong, wrapped in a nostalgic Windows XP-style desktop. I built it in a team of two: I was the product owner and frontend developer, and my teammate (rdennaou) built the backend and the game engine.

What it does

  • Sign up with email and password or with Google
  • Edit your profile and upload an avatar
  • Add friends, see who is online, and chat live
  • Join a matchmaking queue or invite a friend to a match
  • Random power-ups, game themes, and a reconnect window if a player drops
  • Match history, personal stats and a global leaderboard

My part

  • Chose the Windows XP concept and designed the desktop, taskbar, start menu and windows
  • Built the login, register and password-reset pages
  • Built the game interface: the canvas that draws the match, matchmaking, invitations, game over and rematch
  • Built the profile, friends, chat, statistics and leaderboard pages
  • Wrote the Privacy Policy and Terms of Service pages

Technologies

PartTools
Frontend (me)Next.js, React, TypeScript, SCSS, Tailwind CSS, HTML5 Canvas
Backend (teammate)Node.js, Express, Socket.IO, Prisma, JWT
DatabasePostgreSQL on Supabase
InfrastructureDocker Compose and a Caddy HTTPS proxy

The hardest part

One user action can fire several real-time events at once, so menus, matchmaking and navigation could easily show stale information. I solved it by handling all game events in one place and cleaning up listeners when a page closes.

Easter eggs

For fun I added desktop apps inspired by The Hitchhiker's Guide to the Galaxy: Marvin the Paranoid Android answers your questions gloomily, and Deep Thought spends 7,500,000 years computing the answer to life, the universe and everything: 42.
